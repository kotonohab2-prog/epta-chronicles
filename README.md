# EPTA CHRONICLES — Playable Prototype 0.5

スマートフォン横画面を想定した、HTML/CSS/JavaScriptのブラウザ試作版です。

## 起動方法
- ZIPを展開し、`index.html` をChromeまたはEdgeで開きます。
- うまく動かない場合は、プロジェクトフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開いてください。
- スマートフォンで確認する場合は、PCと同じWi-Fi内でローカルサーバーを公開するか、Webホスティングに配置してください。スマホのブラウザでは横向き表示を推奨します。

## 現在遊べる機能
- ホーム画面とメニュー遷移
- 仮キャラクター3人の一覧
- 簡易ターン制バトル（全員攻撃・魔法攻撃・回復・再挑戦）
- 仮ガチャ（★5 1%、★4 14%、★3 85%）
- 実績の達成表示と称号の仮獲得
- 称号獲得通知設定
- ブラウザ内ローカル保存

## 重要な注意
これは企画内容を触って確認するための小さな試作版です。仮キャラクター・仮戦闘バランスを使用しています。オンラインアカウント、サーバー保存、正式なガチャ、課金、全実績・称号仕様、正式ストーリーは未実装です。
